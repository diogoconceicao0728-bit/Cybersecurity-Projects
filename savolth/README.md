# Savolth Front

Landing page institucional da Savolth.

## Stack
- HTML
- CSS
- JavaScript
- Sem backend
- Sem frameworks
- Sem agente / Ollama
- Sem dependências externas

## Direção visual
Front-end premium e imersivo inspirado na linguagem editorial/interativa de sites Awwwards, sem copiar um layout específico.

## Deploy
Site estático compatível com Vercel. Use a pasta `savolth` como Root Directory.
